# Final Cut — Client Delivery

A single-page video delivery site. The film plays inline with custom controls, the page carries its own embedded copy of the video, and the master file is downloadable.

**Files**
- `index.html` — the delivery page (self-contained, video embedded as fallback)
- `final-cut.mp4` — web-optimised master, 1280x720, 60 fps, 41.8s
- `poster.jpg` — thumbnail frame

Open `index.html` directly, or serve the folder with any static host.
